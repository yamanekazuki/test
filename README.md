# 日々の振り返りアプリ

TypeScriptとExpoを使った、日々の振り返りを記録するスマートフォンアプリです。

## 機能

### 2つの振り返りタイプ
- **水平的な振り返り**: 業務スキル・HR課題に関する振り返り
- **垂直的な振り返り**: 感情・内面の成長に関する振り返り（成人発達理論ベース）

### 主要機能
- **振り返りタイプの選択**: 水平的/垂直的を選んで記録
- **構造化された質問**: タイプに応じた専門的な質問を表示
- **ChatGPT連携**: ボタン一つでプロンプト+振り返り内容をコピー
- **スプレッドシート連携**: タブ区切り形式でコピーして簡単転記
- **データの永続化**: AsyncStorageを使用してローカルに保存
- **過去の振り返りを閲覧**: タイプ別に整理された履歴を確認

## 技術スタック

- **React Native**: モバイルアプリのフレームワーク
- **Expo**: React Nativeの開発環境
- **TypeScript**: 型安全なコード記述
- **AsyncStorage**: ローカルストレージ

## セットアップ

1. 依存関係をインストール:
```bash
npm install
```

2. アプリを起動:
```bash
npm start
```

3. デバイスまたはエミュレータでアプリを実行:
- iOS: `npm run ios`（macOS のみ）
- Android: `npm run android`
- Web: `npm run web`

または、Expo Goアプリをスマートフォンにインストールして、QRコードをスキャンして実行できます。

## プロジェクト構成

```
├── App.tsx          # メインアプリコンポーネント
├── types.ts         # TypeScript型定義
├── storage.ts       # AsyncStorageの管理
```

## 使い方

1. **ホーム画面**: アプリを起動すると、今日の日付とこれまでの振り返り回数が表示されます

2. **振り返りを書く**:
   - 「今日の振り返りを書く」ボタンをタップ
   - 振り返りのタイプを選択（水平的 or 垂直的）
   - 表示される質問に沿って振り返りを入力
   - 「ChatGPTで分析」ボタンで、プロンプト+内容をコピー → ChatGPTに貼り付けて分析
   - 「スプレッドシートにコピー」ボタンで、データをコピー → スプレッドシートに貼り付け
   - 「保存」ボタンでアプリ内に保存

3. **過去の振り返りを見る**:
   - 「過去の振り返りを見る」ボタンをタップ
   - 過去の振り返りを日付順に閲覧（タイプも表示）
   - 不要な振り返りは「削除」ボタンで削除可能

## ChatGPTとの連携方法

1. アプリで振り返りを記入
2. 「ChatGPTで分析」ボタンをタップ → クリップボードにコピー
3. ChatGPTを開いて貼り付け
4. ChatGPTが専門的なフィードバックを生成
5. 必要に応じて、フィードバックをスプレッドシートに保存
