# 日々の振り返りアプリ

TypeScriptとExpoを使った、日々の振り返りを記録するスマートフォンアプリです。

## 機能

- **今日の振り返りを書く**: 毎日の気づきや学びを記録できます
- **過去の振り返りを見る**: これまでの振り返りを一覧で確認できます
- **データの永続化**: AsyncStorageを使用して、データをローカルに保存します
- **シンプルで使いやすいUI**: 直感的な操作で振り返りを記録できます

## 技術スタック

- **React Native**: モバイルアプリのフレームワーク
- **Expo**: React Nativeの開発環境
- **TypeScript**: 型安全なコード記述
- **AsyncStorage**: ローカルストレージ

## セットアップ

1. 依存関係をインストール:
```bash
npm install
```

2. アプリを起動:
```bash
npm start
```

3. デバイスまたはエミュレータでアプリを実行:
- iOS: `npm run ios`（macOS のみ）
- Android: `npm run android`
- Web: `npm run web`

または、Expo Goアプリをスマートフォンにインストールして、QRコードをスキャンして実行できます。

## プロジェクト構成

```
├── App.tsx          # メインアプリコンポーネント
├── types.ts         # TypeScript型定義
├── storage.ts       # AsyncStorageの管理
├── app.json         # Expoの設定ファイル
├── package.json     # 依存関係の定義
└── tsconfig.json    # TypeScriptの設定
```

## 使い方

1. **ホーム画面**: アプリを起動すると、今日の日付とこれまでの振り返り回数が表示されます

2. **振り返りを書く**:
   - 「今日の振り返りを書く」ボタンをタップ
   - テキストエリアに振り返りを入力
   - 「保存」ボタンで保存

3. **過去の振り返りを見る**:
   - 「過去の振り返りを見る」ボタンをタップ
   - 過去の振り返りを日付順に閲覧
   - 不要な振り返りは「削除」ボタンで削除可能
